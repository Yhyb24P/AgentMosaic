# Research Agent System v0.1.0

**First stable Rust heterogeneous-Agent team release.**

This is the first stable public release of the Rust heterogeneous-Agent product line.
Earlier `v0.1.0-rc*` and `v1.0.0-rc.*` tags belong to pre-release and historical
development lines; they are not stable releases and are retained unchanged as history.

## What it is

A Rust-based heterogeneous coding/work Agent team. Codex acts as the reference
reasoning/Lead runtime, while Qwen Code is integrated through ACP for delegated worker
tasks. Results and artifacts return automatically to the Lead without manual
Agent-to-Agent copy/paste: one objective in, one durable team result out.

The normal path is a single command:

```bash
agent-code-cli run-team <database> <repo> "<objective>"
```

It creates one durable root task for the objective, runs the real Lead/Scheduler loop
against the real runtime drivers, executes delegated tasks on real workers, and persists
the final answer together with the exact selected task and artifact references.

## Highlights

- one-objective `run-team` product path (plus `resume-team`);
- real Codex Lead and real Qwen Code worker, driven only by the product code;
- durable task/result/message/artifact board in SQLite;
- retry, reassignment and recovery, with no blind replay of interrupted external work;
- resident external runtime bindings;
- schema v11 with a tested migration from the authentic historical v8 schema;
- actual final Codex result fidelity (`thread/read`, exact turn, bounded visible text);
- read-only TUI dashboard; operational control stays on the CLI.

## Known limitations

- Linux x86_64 is the only binary-qualified platform for v0.1.0.
- The TUI is currently a read-only dashboard; operational controls are CLI.
- Kimi, OpenClaw and A2A are not part of this stable reference profile.
- Codex/Qwen authentication is configured in their own runtimes; this project stores no
  model credentials.
- Rust crates are not published to crates.io.

## Install

```bash
tar -xzf research-agent-system-v0.1.0-x86_64-unknown-linux-gnu.tar.gz
cd research-agent-system-v0.1.0-x86_64-unknown-linux-gnu
./agent-code-cli --help
```

Verify the download first:

```bash
sha256sum -c SHA256SUMS.txt
```

See `README.md` for the register/run-team quickstart.
