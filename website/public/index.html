AgentMosaic

Run heterogeneous coding agents as one durable team.

Install

curl --proto '=https' --tlsv1.2 -LsSf \
  https://am.yhshyp.xyz/install.sh | sh

Prebuilt releases currently target Linux x86_64.

GitHub · Latest release

Protocol + LaunchSpec

AgentMosaic coordinates Agents through machine protocols. Each Agent retains control of its own model, provider, credentials and launcher.

Quick start

am init
am agent add lead --role reasoner --adapter codex-app-server -- codex
am agent add worker --role worker --adapter acp -- qwen --acp
am doctor
am run "complete the objective"

Supported adapters: ACP and Codex app-server.
